# Security Policy

## Supported Versions

Only the latest release of StockHome receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of StockHome seriously. Since StockHome is an offline-first application with zero remote telemetry or background internet communication, vulnerabilities typically relate to local data storage, input sanitation, or third-party dependencies.

If you believe you have discovered a security issue:

1. **Do not disclose the issue publicly** via GitHub Issues, discussions, or social media.
2. Please open a [GitHub Private Vulnerability Report](https://github.com/0xCoderunknown/guwahatione_stock-manage/security/advisories/new) or contact the project maintainer directly.
3. Provide detailed steps to reproduce the vulnerability, including:
   - Operating system and Flutter version
   - Reproduction steps or proof of concept
   - Potential impact
4. You will receive an acknowledgment within 48 hours.
5. Once a fix has been verified, an advisory and patch release will be published.
